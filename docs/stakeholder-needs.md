# PulseDesk-KB — Stakeholder Needs (Persona-Based)

Note: As a solo attaché without direct access to real HMIS end users during this build, needs below are derived from the personas and problem statements defined in the official Healthcare KB PRD (v1.1), rather than live interviews.

## Amina, Ward Nurse
- Needs fast answers on patient registration, lab order entry, and discharge steps mid-shift
- Low tolerance for slow or confusing search
- Primarily uses mobile/tablet, so the KB must be responsive
- Would benefit most from the embedded chatbot, since leaving the HMIS mid-task is disruptive

## David, IT Systems Admin
- Manages user accounts, roles, and system configuration across facilities
- Needs detailed technical SOPs, not just quick-reference snippets
- Needs the ability to publish and update content (Editor/Admin role)
- Cares about audit trails and version history for compliance

## Grace, New Hire (Lab Technician)
- Onboarding in her first 2 weeks at the facility
- Needs structured, sequential guidance to build foundational competence, not just isolated reference snippets
- Would benefit from a "Getting Started" category with a clear onboarding path
- Less confident navigating systems, so search must forgive typos and vague queries
