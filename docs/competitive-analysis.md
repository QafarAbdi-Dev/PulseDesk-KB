# PulseDesk-KB — Competitive Analysis

## 1. Stripe Documentation
**What they do well:** Clean, search-first layout with a persistent sidebar and clear typography hierarchy. Easy to scan and navigate even in long technical content.
**What we'll borrow:** Persistent search bar, sidebar navigation for browsing categories, clean typographic hierarchy for article content.

## 2. Intercom Help Center
**What they do well:** Search-first homepage with category cards and featured articles right up front. Very approachable, non-technical tone.
**What we'll borrow:** Homepage layout with category cards and featured/popular articles surfaced immediately.

## 3. Mayo Clinic
**What they do well:** Clean blue-and-white color palette that signals medical trust and professionalism, without feeling like a marketing site.
**What we'll borrow:** Color palette only (medical blue + white/grey backgrounds) — not the layout, since Mayo Clinic is a patient-facing site and PulseDesk-KB is an internal documentation tool.

## Summary & Recommendation
PulseDesk-KB will combine the search-first, sidebar-navigated documentation experience of Stripe Docs and Intercom Help Center with a healthcare-trust color palette inspired by Mayo Clinic. This is not a patient-facing hospital website — it is an internal documentation and support tool for healthcare staff, closer in spirit to Confluence or Zendesk Guide than to a hospital marketing site.
